# Delight: a desk that responds to decisions

The player should feel the market come alive and enjoy exploring a possible outcome, while controls remain immediate and the server remains authoritative.

## Changes

- A small bell beside the market clock swings for 720ms only on an observed preBell → open transition. No sound, overlay, delay, or replay on restoring an open market. Hidden documents skip the effect. Subsequent clock/price frames do not restart it.
- Scenario exploration uses a full-width native range control with a 32px interaction area, a tactile thumb, a visible zero-profit tick when the server provides it, and explicit profit/loss/break-even feedback. The result and thumb change color together. All prices and outcomes remain quoted server stops; the UI only maps the stop index to a marker position.
- Existing purchase stamp, control feedback and panel spacing are preserved. Motion remains independent of OS reduced-motion settings as requested.

## Verification

- Browser: 390×844, 320×740, 1440×900, and compact desktop 1024×768.
- Keyboard Home/End produced profit and loss correctly for both UP and DOWN contracts. Native range semantics and explicit aria-valuetext remain intact.
- Narrow view had matching document client/scroll widths of 305px, accounting for the browser gutter. Compact desktop had no horizontal overflow.
- Confirmed real server opening: clock changed from Market opens in to Closing bell in, computed bell transform showed rotation, then settled to none.
- Three component tests cover single transition playback, restored open state, and hidden-document suppression. All passed.
- TypeScript build, targeted lint, CSS architecture check and production build passed. Design detector returned no findings. Existing comparison bundle size warning remains.

Animation timing was checked through implementation, transition tests, and live computed styles; no frame-time performance profile was recorded.
