# Mascot scratch studies

`/scratch/mascot.html` presents three requested directions: ticket acceptance, closing bell, and the final summary. It preserves the desk's midnight palette, type, restrained borders and spacing. All data is illustrative and no gameplay commands are invoked.

The generated transparent three-pose sheet uses the existing landing mascot as its identity reference. Original output is preserved as `scratch/assets/robopup-poses.png`; prompt and provenance are in `scratch/assets/ROBO-PUP-PROMPT.md`. CSS selects the poses without editing the image. Animations act on complete poses and nearby UI, not independently articulated limbs.

Each study has a replay control; the page also provides mobile-width previews, replay-all and a winning/losing-day toggle. Fixed art slots preserve layout space. Motion is finite, triggered once on entry or explicitly replayed; repeated animations cancel their previous instances. No operating-system reduced-motion suppression, in accordance with the user's stated preference.

Verified desktop and 390px container previews, acceptance replay, summary reveal, win/loss toggle and no container overflow at the compact size. JavaScript syntax check passed. Live gameplay files are unchanged.
