# Game-over summary studies

The user requested alternatives for the game-over summary, presented in a scratch page for selection. No production screen was changed.

`/scratch/summary.html` compares four directions within the approved midnight arcade palette, Lexend/Unbounded type and restrained border treatment:

- Closing receipt: final verdict and a five-day ledger joined by a perforated seam.
- Trading journal: compact result header, daily ledger and selected trade alongside it.
- Balance journey: final result and an actual cumulative end-of-day balance chart derived from the sample day changes.
- Arcade scorecard: rank-led centered composition, with the selected ticket-strip language for reviewing days.

Shared controls switch between profit, loss, sitting out and a large win, toggle mobile-width previews, and replay finite entrances. Real rank thresholds and lesson copy are imported from the app; all monetary records are explicitly illustrative. Play again is a labelled scratch interaction that explains its real-game behavior without starting a game. Selections, cost, returned money and net result agree across all four versions.

Verified desktop and mobile-width compositions, 320px document fit, all four outcome scenarios, keyboard day selection, lessons disclosure and preview-only action. No functional text overflow was found; ticket/receipt notches intentionally extend into their parent surfaces. JavaScript syntax check passed. Scratch files are outside the production entry, and no backend or game state is used.
