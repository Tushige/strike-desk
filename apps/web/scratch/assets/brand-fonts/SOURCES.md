# Font provenance

Self-hosted Latin variable WOFF2 files for the identity scratch studies. Each was downloaded from its Fontsource npm package at version 5.3.0 through jsDelivr. Original OFL licenses are included alongside the fonts. No package dependencies or production fonts were changed.

- Bricolage Grotesque: https://fontsource.org/fonts/bricolage-grotesque — `@fontsource-variable/bricolage-grotesque@5.3.0/files/bricolage-grotesque-latin-wght-normal.woff2`
- Sora: https://fontsource.org/fonts/sora — `@fontsource-variable/sora@5.3.0/files/sora-latin-wght-normal.woff2`
- Space Grotesk: https://fontsource.org/fonts/space-grotesk — `@fontsource-variable/space-grotesk@5.3.0/files/space-grotesk-latin-wght-normal.woff2`
